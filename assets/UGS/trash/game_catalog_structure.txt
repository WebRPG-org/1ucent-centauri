Note
This document specifies the official catalog structure and path mapping schema for the Centauri Arcade Hub database.
Schema & Format Specification:
1. Folder Headers: Top-level directory names (e.g., 1-9, A, B, ..., Z).
2. Separator Line: A single hyphen (-) directly below each folder name header.
3. Game Item Mapping: Formatted as (Clean Title) = (File Identifier / File Name).
   * Clean Title: Human-readable game name used in user interface displays and search indexing.
   * File Name: Relative filename or raw ID (typically prefixed with cl and suffix .html).
Resolver Guidance for Developers and LLMs:
* To dynamically construct game asset URLs, combine the active CDN or base path, the respective folder name, and the filename:
{BaseURL}/{FolderName}/{FileName}
Example: assets/games/1-9/cl1v1lol.html or assets/games/R/clretrobowl.html
* When adding new entries, preserve alphabetical sorting within each folder and ensure all clean titles contain their corresponding file identifier.
